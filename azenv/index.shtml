// faq
这个页面是干什么的？

它把你的连接所发送的请求头、以及服务器能看到的环境变量原样回显出来 —— 和 Web 服务器看到的完全一致。代理 / VPN 用户用它来判断自己的连接泄露了什么。

什么是 REMOTE_ADDR？

请求到达的 IP。走代理 / VPN 时它应该是代理的地址，而不是你的。如果这里出现了你的真实 IP，说明有泄露。

什么是 X-Forwarded-For？

代理添加的、用于携带原始访客 IP 的请求头。透明代理会原样保留它，从而暴露你想隐藏的地址；配置得当的匿名代理会移除或替换它。

怎么判断我的代理是否匿名？

把这些值和你的真实 IP 对比：如果 REMOTE_ADDR 是代理的、且没有任何字段携带你的地址，说明代理在保护你；只要你的 IP 出现在任一字段里，就没有。

为什么有些值是 [redacted]？

可能携带凭据的请求头（如 Cookie、Authorization）永不回显 —— 即使对你也不回显，避免截图或中间代理截获。
